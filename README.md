# Service Booking Web Application

## About

This is a simple Service Booking Web Application. I made this project to practice working with HTML, CSS, and JavaScript.

The application allows users to browse different services, select services, add them to a cart, view the total amount, and confirm their booking.

## Technologies Used

HTML

CSS

JavaScript

## Features

Displays different services with images and prices

Allows users to select services

Removes a service when Skip Item is clicked

Adds selected services to the cart

Updates the total amount automatically

Provides a booking form

Checks form fields before confirming a booking

## Operations Performed

1. Browse Services

Displays different services with their images and prices.

2. Select Services

Allows users to select services using the Add Item button.

3. Skip Services

Removes the selected service card from the page when the Skip Item button is clicked.

4. Add to Cart

Adds selected services to the cart.

5. Calculate Total

Calculates and displays the total amount of all items in the cart.

6. Book Now

Takes the user to the booking form.

7. Confirm Booking

Checks the entered details and displays a booking confirmation message.

## How to Run

Create three files named index.html, style.css, and script.js.

Add the respective code to each file.

Open the index.html file in a browser.

Browse the available services.

Click Add Item to select a service.

Click Skip Item to remove a service from the page.

Click Add to Cart to add selected services to the cart.

Click Book Now and fill in the booking form.

Click Confirm Booking to complete the process.
